# Security Fix: Path Traversal Vulnerability

Fixed a path traversal vulnerability in `src/lib/supabase.ts` where the `path` argument was directly concatenated into the filename without sanitization when uploading parking lot images.

```typescript
const sanitizedPath = path.replace(/[^a-zA-Z0-9_-]/g, '');
const fileName = `${sanitizedPath}-${crypto.randomUUID()}.${fileExt}`;
```
