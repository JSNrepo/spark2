# Agent Run Log - Bolt Optimization

## What you discovered
During profiling, it was identified that the `MapView` component in `src/pages/Search/SearchPage.tsx` was not memoized. As a result, the `SearchPage` state updates (like `searchQuery` state, updating on every keystroke in `LocationSearch`) caused the entire heavy `MapView` (which uses `react-leaflet`) to re-render, leading to significant input lag and unnecessary DOM updates.

## What you fixed/added
- Wrapped the `MapView` component in `src/components/Map/MapView.tsx` with `React.memo()`.
- Since `MapView` only receives stable or derived props (`parkingLots`, `showUserLocation`, `center`, `zoom`, `filters`), wrapping it in `React.memo()` successfully protects it from unnecessary re-renders when the `SearchPage` frequently updates its search query state.

## Next Recommended Target
Investigate if `LocationSearch` (which also receives keystrokes and maintains its own state) can be similarly optimized, or if the `SearchPage` state for search query could be refactored to minimize top-level re-renders by utilizing uncontrolled components with a debounced local state wrapper.
