## What you discovered
- I noticed that in `src/components/Search/AdvancedFilters.tsx`, there was an inline object `{ covered: '...', security: '...', ev_charging: '...', accessible: '...' }` inside `Object.entries(...)` that was being created and mapped over within the component's render body.
- This creates unnecessary object memory allocations on every render for the React component.

## What you fixed/added
- I moved the `Object.entries({ ... })` evaluation completely outside of the `AdvancedFilters` component scope as a constant `FEATURES_LIST`.
- Now, the component maps over `FEATURES_LIST`, avoiding multiple O(N) array iteration and reallocation on every render.
- I added a `⚡ Bolt Optimization:` comment to explain the purpose of this change.
- Additionally, documented learning in `.jules/bolt.md`.
