What you discovered.
In `src/pages/Info/HelpCenter.tsx`, I found inefficient array operations during rendering. The `categories` array was statically allocated within the functional component, causing unnecessary memory reallocation on every render. Furthermore, calculating the filtered list involved chaining `.map()` and `.filter()`, leading to multiple iterations over the list.

What you fixed/added.
- Moved the `CATEGORIES` array outside the component to ensure it is allocated only once.
- Refactored `filteredCategories` computation using a single-pass `reduce` loop to avoid multiple $O(N)$ operations.
- Wrapped the derived state calculation in `useMemo` so it's only recalculated when the `searchQuery` changes.

Next Recommended Target
I recommend looking into other pages containing large lists (such as `SearchPage.tsx` or `Dashboard.tsx`) to ensure lists are optimized with `useMemo` and complex nested array methods are reduced to a single-pass loop where practical.
