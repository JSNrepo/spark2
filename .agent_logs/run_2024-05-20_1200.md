# Palette Run Log
## What you discovered
The image gallery carousel on the `ParkingLotDetails` page lacked semantic accessibility attributes. The dot indicators and thumbnail selectors were interactive buttons but had no `aria-label`, no indicator of current state (`aria-current`), no clear keyboard focus ring (`focus-visible`), and the screen reader would read out empty alt-texts for decorative thumbnails inside already-clickable buttons.

## What you fixed/added
- Added `aria-label`s to both dot indicators ("View image X") and thumbnail buttons ("Select image X").
- Added `aria-current={true}` when an image is actively selected.
- Added explicit keyboard focus states (`focus-visible:ring-2 focus-visible:ring-blue-500`) to both sets of controls.
- Added `aria-hidden="true"` and `alt=""` to the thumbnail `<img>` elements to avoid redundant screen reader announcements.
- Updated `.Jules/palette.md` with the custom carousel accessibility learning.
