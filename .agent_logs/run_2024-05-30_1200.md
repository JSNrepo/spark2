# Agent Run Log

## What you discovered
- The `BookingCard` component in `Dashboard.tsx` and `ParkingLotItem` in `ProviderDashboard.tsx` were wrapped in `React.memo()`.
- However, the parent components were passing down unmemoized functions (`getStatusColor`, `getPaymentStatusColor`, and `handleDeleteLot`) as props.
- This recreated the function references on every parent render (e.g., when a user changed the "filter" state), changing the prop reference and completely defeating the `React.memo()` optimization, causing O(N) re-renders of the list items.

## What you fixed/added
- Extracted pure helper functions (`getStatusColor`, `getPaymentStatusColor`) from `Dashboard.tsx` component body to module scope.
- Wrapped `handleDeleteLot` in `ProviderDashboard.tsx` in a `useCallback` hook with the proper `loadProviderData` dependency.
- This stabilizes the prop references and restores the O(N) rendering optimization of `React.memo`.

## Next Recommended Target
- Investigate `useForm`'s `watch()` in `BookingPage.tsx` causing frequent re-renders during date/time selection, and consider migrating to `useWatch` to isolate re-renders.
