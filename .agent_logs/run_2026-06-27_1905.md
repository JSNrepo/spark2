What you fixed/added:

I updated the `setTimeout` calls to first clear any existing timeout using `clearTimeout(timeoutRef.current)` and then capture the new timeout ID. Additionally, I implemented a `useEffect` hook returning a cleanup function to explicitly call `clearTimeout` upon component unmount, ensuring the unhandled timeout memory leak is properly prevented.
