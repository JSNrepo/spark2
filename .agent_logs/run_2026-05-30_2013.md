What you discovered.

This warning was triggered because `src/contexts/AuthContext.tsx` exported both the `AuthProvider` component and the `useAuth` hook.

I fixed the ESLint warning by extracting the `useAuth` hook and the `AuthContext` definitions into a separate file `src/hooks/useAuth.ts`. I updated `src/contexts/AuthContext.tsx` to import `AuthContext` from the new hook file, and updated all usages of `useAuth` across the project (in `Header.tsx`, `App.tsx`, `ProviderDashboard.tsx`, `CreateParkingLot.tsx`, `Login.tsx`, `SpaceProviderRegister.tsx`, `Register.tsx`, `Dashboard.tsx`, `ParkingLotDetails.tsx`, `BookingPage.tsx`, and `ProfilePage.tsx`) to import from `../../hooks/useAuth`.
