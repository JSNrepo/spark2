# Phase 3 Log

## What you discovered.
I discovered that several images in `src/pages/Home.tsx` located below the fold (in the "How It Works" and "Testimonials" sections) were being loaded eagerly. Eager loading of off-screen images wastes bandwidth and degrades initial page load performance, negatively impacting Largest Contentful Paint (LCP) and overall user experience.

## What you fixed/added.
I added the `loading="lazy"` and `decoding="async"` attributes to the `<img>` elements representing the "How It Works" step images and the "Testimonials" user avatars. I also added a Bolt-specific comment explaining the performance rationale (`{/* ⚡ Bolt Optimization: Lazy load off-screen images to improve page load performance and save bandwidth */}`). I intentionally left the hero image loading eagerly as it is critical for LCP.

## Next Recommended Target
Investigate code splitting and lazy loading of route components in `src/App.tsx` (or the main router configuration) to further reduce the initial Javascript bundle size, as the current `dist/assets/index-*.js` bundle is quite large (~360KB).
