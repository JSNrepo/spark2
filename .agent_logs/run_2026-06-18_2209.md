## What you discovered
- The React `AuthContext` value was re-created on every render of `AuthProvider`, causing unnecessary re-renders across all context consumers even when user and loading states remained the same.
- In `src/components/Map/MapView.tsx`, several pure functions (`getAvailabilityLevel`, `getParkingType`, and `calculateDistance`) were defined inside the component body, meaning they were unnecessarily recreated on every render of the map.

## What you fixed/added
- Added a `useMemo` hook to wrap the `value` object in `src/contexts/AuthContext.tsx` to stabilize its reference and prevent widespread unnecessary component re-renders.
- Moved the pure functions `getAvailabilityLevel`, `getParkingType`, and `calculateDistance` outside of the `MapView` component body (to module scope) to prevent memory reallocation and recreation on every map render.
