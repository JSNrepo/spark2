# Run Log

## What you discovered
- The social media links in `src/components/Layout/Footer.tsx` were icon-only elements that lacked explicit accessible names (`aria-label`, `title`), proper keyboard focus styles, and the `aria-hidden="true"` attribute on their inner decorative Lucide icons.
- This creates accessibility barriers for screen reader and keyboard navigation users.

## What you fixed/added
- Added explicit accessible names using `aria-label` and `title` to all social media links in the footer.
- Applied specific focus styles (`focus:outline-none focus-visible:ring-2 focus-visible:ring-blue-500 focus-visible:ring-offset-2 focus-visible:ring-offset-gray-900 rounded`) to ensure they are visible when navigating by keyboard.
- Added `aria-hidden="true"` to the inner decorative `lucide-react` icons to prevent redundant or confusing screen reader announcements.
- Generated a visual verification screenshot via Playwright to confirm the focus states and added an entry to `README.md`.
- Appended a critical UX learning about icon-only links to `.Jules/palette.md`.

## Next Recommended Target
- Review other instances of icon-only interactive elements across the application, especially in headers and map view controls, to ensure consistent application of accessible names and focus indicators.
