# Sentinel Run Log

**What you discovered:**
Found Personally Identifiable Information (PII) leakage in `src/contexts/AuthContext.tsx`. Specifically, `console.log` statements were printing user email addresses to the client-side console during sign-in and profile-fetching events.

**What you fixed/added:**
Replaced `user.email` references in `console.log` statements with `user.id` or removed them entirely to ensure PII is no longer leaked into browser developer tools.
