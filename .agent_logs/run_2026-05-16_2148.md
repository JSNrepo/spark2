### What you discovered
The `ParkingLotCard` component rendered images without native lazy loading attributes. On search pages where multiple cards are loaded simultaneously, this eager loading can cause unnecessary bandwidth consumption and negatively impact initial page rendering performance as off-screen images are loaded unnecessarily.

### What you fixed/added
Added `loading="lazy"` and `decoding="async"` to the `<img>` tag in `src/components/ParkingLot/ParkingLotCard.tsx`. I also included an explanatory comment highlighting the performance optimization rationale, resolving the code review feedback. This ensures the browser only requests these images when they approach the viewport and decodes them off the main thread.
