# Scout
Discovered that `src/pages/Booking/BookingPage.tsx` was computing derived state (`totalAmount`, `totalHours`) using `useState` and `useEffect`, causing unnecessary secondary re-renders when form inputs changed.

# Execute
Replaced the derived state `useState` variables and the synchronization `useEffect` with a single `useMemo` hook returning an object containing both values. This optimizes performance by calculating derived state synchronously during the render cycle.
