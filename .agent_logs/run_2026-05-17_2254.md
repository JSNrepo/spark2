### What you discovered
The mobile menu toggle button in `src/components/Layout/Header.tsx` was missing critical accessibility attributes, rendering it opaque to screen readers, and lacked keyboard focus indicators.

### What you fixed/added
Added dynamic `aria-label`, `title`, and `aria-expanded` attributes to the mobile menu button. Hid the decorative `lucide-react` SVG icons using `aria-hidden="true"`. Added specific `focus:outline-none focus-visible:ring-2 focus-visible:ring-blue-500` styles to provide clear visual feedback during keyboard navigation. Logged this pattern in `.Jules/palette.md`.

### Next Recommended Target
Ensure other icon-only interactive elements (like the search icon or close buttons in modals) follow this standardized stateful toggle accessibility pattern.
