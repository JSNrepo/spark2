## What you discovered
The `signIn` and `signUp` functions in `src/contexts/AuthContext.tsx` were directly passing raw backend error messages (`error.message` from Supabase) to `toast.error()`. This is a security risk as it can leak sensitive backend information or facilitate user enumeration.

## What you fixed/added
Modified `src/contexts/AuthContext.tsx` to display safe, generic error messages to the user ("Invalid email or password" and "Registration failed. Please check your details and try again.") while preserving the original error logging via `console.error` for debugging purposes.

## Next Recommended Target
Review API endpoints and other data mutation functions to ensure error handling is robust and does not leak raw database errors or stack traces to the frontend UI.
