# Agent Run Log

## What I discovered
While reviewing the `AdvancedFilters.tsx` component, I noticed that the grouped interactive elements (Price Range inputs and Features checkboxes) were wrapped in generic `<div>` elements with faux labels. This structural pattern breaks the semantic association for screen readers, as they cannot correctly group the inputs or announce the group title.

## What I fixed/added
- Replaced the `<div>` wrappers for the "Price Range" and "Features" groups with `<fieldset>` tags in `src/components/Search/AdvancedFilters.tsx`.
- Changed the pseudo-label `<div>` elements to semantic `<legend>` tags to ensure screen readers correctly associate the group title with the nested interactive inputs.
- Preserved existing Tailwind utility classes to ensure there were no visual regressions.
