🚨 Severity: CRITICAL
💡 Vulnerability: Path traversal vulnerability in `uploadParkingLotImage` function where the `path` argument was directly concatenated into the filename without sanitization when uploading parking lot images.
🎯 Impact: Attackers could potentially use path traversal characters (like `../`) in the `path` parameter to store files in unintended directories or potentially overwrite other resources in the Supabase storage bucket.
🔧 Fix: Sanitized the `path` parameter using a regex to allow only alphanumeric characters, hyphens, and underscores before constructing the filename.
✅ Verification: The application builds successfully and tests pass.
