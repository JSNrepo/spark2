💡 What: Refactored `totalAmount` and `totalHours` in `src/pages/Booking/BookingPage.tsx` from using `useState` and `useEffect` to a single `useMemo` computation.

🎯 Why: To solve a performance anti-pattern. Previously, whenever the user typed in the date or time fields (or when the `parkingLot` data loaded), the form would re-render. Then the `useEffect` would fire, update the `totalHours` and `totalAmount` state variables, triggering a *second*, unnecessary re-render.

📊 Impact: Eliminates the secondary re-render bottleneck when users are filling out the booking form, making the UI noticeably more responsive.

🔬 Measurement: Check the React DevTools profiler while manipulating the start/end date and time inputs. The component should now only render once per input change, instead of twice.

### Agent Log
# Scout
