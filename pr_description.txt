## 🎨 Palette: Grouped Input Accessibility Fix

### 💡 What:
Replaced generic `<div>` wrappers with semantic `<fieldset>` and `<legend>` tags for the "Price Range" and "Features" filter groups in `AdvancedFilters.tsx`.

### 🎯 Why:
Screen readers struggle with visually grouped inputs (like a set of checkboxes) when they are wrapped in plain `<div>` elements with pseudo-labels. By using native `<fieldset>` and `<legend>` elements, we ensure that assistive technologies correctly associate the group title (e.g., "Features") with each individual input within the group, making the filter panel fully accessible.
