💡 What:
Moved the static `organizationTypes` and `amenityOptions` arrays outside of their respective React component bodies (`SpaceProviderRegister` and `CreateParkingLot`).

🎯 Why:
Defining static arrays inside a functional component body causes the array to be re-allocated in memory on every render. Even if the array content is completely static, the memory reference changes, causing unnecessary garbage collection and degrading overall rendering performance, especially during form input keystrokes.

📊 Impact:
Reduces unnecessary memory allocations to exactly once per module load, improving rendering speed and input latency.

🔬 Measurement:
1. Start the dev server (`pnpm dev`).
2. Navigate to `/register/space-provider` or `/provider/parking-lot/new`.
3. Type into any of the text inputs and observe improved input response times. Profiling the component will show that the arrays are no longer re-created on each keystroke.
